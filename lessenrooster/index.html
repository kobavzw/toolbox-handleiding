Lessenrooster

Via de module Lessenrooster kan je het lessenrooster importeren vanuit de volgende roostersoftware: EDT, Mondriaan, Untis en MyRo. Na de import kan je vanuit Toolbox het lessenrooster importeren in Smartschool en ook meteen de juiste leerkracht aan de juiste klassen koppelen. Het lessenrooster is eveneens nodig om de module Vervangingslijsten te kunnen gebruiken.

Wanneer het lessenrooster geïmporteerd is, is het raadpleegbaar in de module Adresboek. Het personeelslid in kwestie kan het actieve lessenrooster ook steeds bekijken via zijn profiel in Toolbox.

📄️Uurrooster beheren

Module Lessenrooster: uurrooster beheren, actief lessenrooster, controle lessenrooster, opbouw lessenrooster.

📄️Roosterbestand uploaden

Module Lessenrooster: roosterbestand uploaden, importeren, afwezigheden, vervangingen.

📄️Rooster verwijderen

Module Lessenrooster: rooster verwijderen, Smartschool.
